# Demo & Pattern Files

These files demonstrate lower-level Praman patterns and are **not** part of the core process suites (OTC / PTP / RTR / ATR / HTR).

They are kept for onboarding and reference:

| File | Purpose |
|------|---------|
| `flp-navigation.spec.ts` | Launchpad tile / semantic object / home / back |
| `fiori-elements-list-report.spec.ts` | `fe.listReport` + `fe.objectPage` patterns |
| `ui5-controls-demo.spec.ts` | Button, Input, Table, Dialog, DatePicker gold patterns |
| `business-intent.spec.ts` | High-level `intent.*` APIs |
| `example-purchase-order.spec.ts` | Original combined example |

Prefer writing new business scenarios under the process folders (`otc/`, `ptp/`, etc.).
